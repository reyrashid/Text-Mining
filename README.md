# Text-Mining
This repositiry contains code for assignments completed during the text mining course. The project focuses on negation scope detection (identifying the words affected by a negation cue within a sentence).

Models: 
1. A feature-based Conditional Random Field (CRF) model was developed to label the scope of negation given a negation cue. The workflow includes dataset preprocessing, feature engineering, CRF model training, evaluation, and error analysis.

2. A BERT model was fine-tuned to identify the scope of negation given a negation cue. The workflow includes data preprocessing and preparation, BERT fine-tuning, model evaluation, and comparison with the feature-based approach
